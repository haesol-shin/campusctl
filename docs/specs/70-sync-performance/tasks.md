## Parallel map

P1a || P1b → P1c → P1d → P2a → (P2b || P2c || P2d || P2e) → P2f → P2g → P3 → P4. The provider lanes hand files over from 60 before starting; U5 owns CLI/command wrappers throughout. 40-fetch can work on its new package/detail adapters in parallel, but its domain command registrations wait for U5. The integration lane serializes all contracts/changelog/version changes.
