# Selected assignment and notice source packages

[Constitution](../constitution.md) · [Design](design.md) · [Tasks](tasks.md)

Assignment and notice fetch are registered for the v0.4.0 release candidate; owner sign-off and live confirmation of notice fetch after the notice-detail fix remain release gates (see [tasks](tasks.md)). A fetch accepts exactly one full entity ID from the matching catalog, opens that detail through the ordinary course UI, independently verifies the selected course/item identity, and packages complete readable text. It does not submit work, click mark-read, save video/audio or interact with grading, attendance or enrollment. Opening a notice detail can increment its view count and flip read state as ordinary reading; record this effect in the [live run](../live-run.md).

Included same-origin images and officially selected non-video attachments retain bytes, type, size, hash and normalized query-free provenance. External, media and unknown-type references become explicit omissions without a transfer; notice attachments remain omissions until an attachment-bearing notice is observed and approved. A technical transfer or identity failure publishes no package. The manifest stores selected ID, course, kind, source reference, retrieval timestamp, completeness, included resources, omitted resources and SHA-256 hashes. Resource IDs are deterministic from selected native file identity or inline reference order, including omitted references. Safe NFC names stay below 200 UTF-8 bytes, reject traversal/symlinks, and resolve collisions deterministically. Publish atomically and reuse byte-identical default packages; never overwrite an explicit destination.

Browser pages issue their ordinary requests without a route guard. Only a selected official attachment transfer has file-identity, response type/signature and size checks. The shared browser lock ensures `busy` never appears as an empty success. Fetch does not use material-list numbers and has no `--course` flag; it requires a headed browser, and `--headless` returns `headless-unavailable`.
