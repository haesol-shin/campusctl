# Source-package design

[Requirements](spec.md) · [Constitution](../constitution.md)

The unpublished `assignments fetch ENTITY_ID` and `notices fetch ENTITY_ID` paths accept one full catalog ID. Resolve the row before browser launch, select its course via the ordinary roster/menu route, open only that detail and compare its committed page and native response identities to the selected row. Never match by title or position. Capture ordered readable text in `content.md`, rewrite included local resource links, and render explicit omission markers for external, video/audio, unknown or unobserved notice attachments. A notice detail can add one view and may change read state; report observed state, without clicking explicit read controls.

For notices, the committed detail URL and `POST /api/v1/board/notice/info` body must identify the selected native board item and course. Read the title and HTML content from that verified response, parse inert text and link labels, check supported images, and omit video/audio and each unverified attachment-list entry. The notice-detail DOM has not been observed live and is not used as an identity or content source [owner-held sanitized evidence (2026-09-27)].

`package.json` records selected full ID, kind, course, normalized source reference (origin/path without query), retrieval time, content path, completeness, included SHA-256 resources and ordered omissions. Hash canonical manifest content without retrieval time plus content and resources for a stable package digest. Resource IDs derive from the native selected file ID or selected entity and one-based inline-reference order. Keep duplicate uses consistent; a conflicting reuse fails. Normalize names (NFC, basename, reserved/device-name safety, 200-byte UTF-8 final component), contain outputs and reject symlinks. Publish a complete package atomically under a private digest path or a new explicit `--out` directory; a technical failure never leaves a visible partial package.

Pages run unfiltered. For an officially selected attachment, reuse the materials transfer's selected-file identity, response/signature and 200000000-byte checks. Notice attachments remain omissions until observed and approved. The single account lock covers browser work and publication; `busy`/75 returns no package. A policy omission yields a usable, explicitly partial package; a failed transfer yields no package. The public CLI contract and capability list do not advertise fetch until owner sign-off.
