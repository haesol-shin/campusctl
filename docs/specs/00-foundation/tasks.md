# Foundation verification

[Requirements](spec.md) · [Design](design.md) · [Constitution](../constitution.md)

- Verify full, filtered, partial and failed-discovery catalog merges retain stale rows and isolate domains

- Check ordinary LMS page requests remain unfiltered while selected-file downloads alone enforce file binding and response checks
- Follow the [live run protocol](../live-run.md) for LMS behavior changes; record observations in the owner's local notes, not public fixtures
