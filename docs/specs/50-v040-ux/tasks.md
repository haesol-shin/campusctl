# CLI UX verification

[Requirements](spec.md) · [Design](design.md)

- Check combined sync domains, shared selection and per-domain partial results without clearing failed catalogs
- Exercise printed course/file numbers, changed-generation errors, full-ID JSON selection and the single-file human picker
- Check cached lists/status remain offline, report stale coverage and use Asia/Seoul date boundaries
- Exercise guided setup from missing, existing and declined states with hidden credentials and optional sync
- Check global headless/headed precedence, CDP/playback refusal and profiling output on stderr
