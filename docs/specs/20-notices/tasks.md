# Notice verification

[Requirements](spec.md) · [Design](design.md)

- Check multiple course boards and absent global to-do matches still publish all board notices with unknown read state
- Check matched native and unique fallback identities preserve legacy date and ordinal without confusing another course
- Check paginated, inconsistent, absent and duplicate responses retain previous rows and name the failing board step
- Check a verified empty board clears its prior rows, menu-click entry follows verified course selection, and sync opens no detail
- Follow the [live run protocol](../live-run.md) for LMS behavior changes
