# Official course materials

[Constitution](../constitution.md) · [Design](design.md) · [Tasks](tasks.md)

`sync` includes materials metadata in the combined pass; `sync --only materials` narrows it. Archive entry uses the selected course's rendered menu. One official file control gives one row, including nondownloadable types; posts with no files give none. Check modal targets, then inline controls. If a post cannot be resolved, fail its course and retain old rows as stale. Preserve raw `display_name`; remove only a trailing `바로보기` label and adjacent whitespace from the saved `filename`. List is local, `--refresh` syncs materials first, and human output numbers individually selectable rows while retaining full IDs.

Download accepts exactly one full listed ID, or a number from the last successfully printed human materials list; a bare human dual-TTY invocation offers a single-choice picker. A changed catalog invalidates numbers. JSON clients pass full IDs. Revalidate the selected board and official file control before any transfer. Only approved non-video attachment types up to 200000000 bytes can be saved. Bind the actual transfer to the selected file and verify response status, MIME/signature or extension-specific signature/text, declared/streamed size and full SHA-256. PDF, PPTX and ZIP use the observed strict pairs in the [constitution](../constitution.md). ZIP is stored, never extracted. An unknown, moved, external, video/audio or mismatched file is not published.

The default output is the OS Downloads folder under `campusctl/<safe course label>/` (including redirected Windows Downloads); `--out` chooses a directory. Names are contained, normalized, symlink-safe, at most 200 UTF-8 bytes per component, and published atomically without overwrite. A verified same-ID/same-destination receipt can skip transfer; an interrupted transfer restarts without HTTP Range. Catalog failure retains stale rows while other domains proceed. LMS page requests run unfiltered; only the selected-file transfer is constrained.
