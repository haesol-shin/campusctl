## v0.4.0 precedence and integration

The owner-approved 50/60/70 deltas supersede earlier specs only for explicitly named UX, browser mode, replay and traversal contracts; all identity, read-only, media and publication safeguards remain. These are implementation plans, not current public capabilities. 40-fetch remains the sole detail/package specification and retains its evidence gates; its adapters can proceed alongside new local UX modules, while shared domain command registration waits for 50's integration owner. Release integration serializes release docs/version/changelog and final validation; spec writers do not commit.

Integration order: 50 local interfaces → local status/setup and 60 mode/player in parallel → 50 CLI integration → 60 provider handoff → 70 measured provider refactor → 40 command publication when cleared → release integration. Every new folder names owned files, behavioral tests, explicit errors and unresolved evidence. No live LMS use is authorized by these plans.
